# 口述史公开版授权封存台

这是面向地方档案馆的口述史公开版治理应用。系统把原始录音与授权文书基线冻结、片段与约束批量登记、授权覆盖诊断、增量冲突检查、遮蔽预演、独立复核、退回任务闭环和不可变公开清单封存收束在一条可追溯流程中。

浏览器工作台由 Go 服务直接提供，不需要 Node.js 构建。所有数据保存在本地目录中，包括案件 JSON 快照、持久幂等响应、带前序摘要的追加式审计事件和终态公开清单。

## 环境要求

- Go 1.22 或更高版本
- 可用的本地回环端口

## 构建

```bash
go build ./cmd/oralhistory
```

## 运行

默认监听 `127.0.0.1:19081`，默认数据目录为 `./oralhistory-data`：

```bash
go run ./cmd/oralhistory
```

显式指定监听地址和数据目录：

```bash
go run ./cmd/oralhistory -addr=127.0.0.1:19082 -data-dir=./oralhistory-data
```

也可以通过 `PORT` 指定端口号，服务会绑定到 `127.0.0.1:<PORT>`。服务拒绝非回环监听地址。启动后访问 `http://127.0.0.1:19081/` 使用工作台。

## 测试

运行全部单元与适配层测试：

```bash
go test ./...
```

运行有界全流程自检。该命令使用临时数据目录和真实回环 HTTP，依次完成建档、冻结、冲突整改、首次退回、限定修订、再次送审、批准封存和摘要验证，然后主动退出：

```bash
go run ./cmd/oralhistory -self-check -addr=127.0.0.1:19081
```

## 业务约束

- 档案员与复核员必须是不同人员。
- 原始录音和授权文书摘要冻结后不可直接替换。
- 每次写操作都需要 `expected_revision` 和 `request_id`，用于防止陈旧覆盖和支持幂等重放。
- 批量登记先返回按记录类型、行号和字段定位的预检结果；确认后整批只产生一个修订和一条审计事件，任一记录失败均不落库。
- 工作台按当前修订即时计算人物与主题的授权覆盖矩阵，并显示未覆盖、策略歧义和已届满延后期限。
- 冲突检查记录输入与结果摘要及相对上次的新增、解决、重开和未变化项；片段、约束或整改变化会让旧检查立即过期。
- 阻断冲突全部得到带理由和证据的有效处置后，才能生成只读候选公开版。
- 静音区间、匿名别名、证据引用和排除字段须先通过无写入预演，确认后才保存规范化处置。
- 复核退回后只允许修改意见明确指出的片段；每条意见形成跨轮次可追踪任务，再次送审显示候选版逐片段差异和异常变化。
- 批准后生成不可变公开清单，可按时间、片段和公开/排除类型只读查询，并逐项重算五类摘要与片段结构结果。

## 数据目录

数据目录包含以下子目录：

- `cases/`：当前案件聚合快照。
- `events/`：按案件追加的审计事件帧。
- `idempotency/`：按 `case_id` 和 `request_id` 保存的响应记录。
- `manifests/`：批准后生成的不可变公开清单。

启动恢复会检查事件序号、前序摘要和帧摘要连续性。若发现截断尾帧、摘要不匹配或快照修订与事件数不一致，服务会拒绝启动并给出明确诊断。
